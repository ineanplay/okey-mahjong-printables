# Contributing

Please report language, page, printer paper size and scaling for a layout defect. For a rule-related correction, name the rule version and link a public source. Original translations and accessible layout improvements are welcome as focused pull requests.

Do not upload completed sheets containing private player/customer information, internal training originals or commercial rule cards. New original content uses CC BY 4.0; code contributions use MIT. Preserve source attribution and note changes.

## 中文

排版问题请注明语言、页码、纸张及缩放设置；规则问题请注明版本并附公开来源。欢迎原创翻译与无障碍改进。不要上传含个人或客户资料的已填写表格、内部培训原件或商业牌例卡。新增原创内容采用 CC BY 4.0，代码采用 MIT；保留署名并说明改动。

## About INEAN PLAY

INEAN PLAY focuses on automatic OKEY tables, automatic Mahjong tables and compatible accessories, providing products and practical support for homes, clubs, cafés and game rooms. We maintain free community resources to help enthusiasts learn, organize games and care for their equipment. Corrections, translations and improvements are welcome.

This project provides printable score sheets and session records for players, teachers and clubs.
