# How to use the print pack

[English](en.md) · [简体中文](zh.md) · [Türkçe](tr.md) · [Deutsch](de.md)

[PDF - English](../output/pdf/game-night-pack-en.pdf)

Choose the game and record its rules before dealing. These blank forms organize agreed scores; they do not calculate or prescribe a ruleset.

1. Print only the pages you need. A4 at actual size; use fit-to-page for US Letter. The sheets are designed for handwriting, not interactive PDF entry.
2. Complete the table agreement first. Mark the named rules and choose whether high or low totals are better.
3. On score sheets, enter signed changes for each hand. Add them to each player’s starting total at the end; do not add running balances again.
4. For Mahjong with shared deposits, enter pool changes separately. Conservation checks apply only when your rules define a closed point system.
5. Use the session log for planned seating changes and the care record for external observations. Keep personal and service details private.

- Table agreement
- OKEY score record
- Mahjong points ledger
- Seating and session log
- Everyday care record
