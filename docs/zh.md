# 打印包使用说明

[English](en.md) · [简体中文](zh.md) · [Türkçe](tr.md) · [Deutsch](de.md)

[PDF - 简体中文](../output/pdf/game-night-pack-zh.pdf)

先选玩法，再约定规则。这些空白表用于记录约定的分数，不自动计算，也不指定一套通用规则。

1. 按需要选择页面打印。A4 采用实际尺寸，US Letter 采用适合页面。本套为手写表，不是交互式 PDF 表单。
2. 先填写桌规约定，写明规则版本及高分好还是低分好。
3. 计分表每局填带正负号的分数变动。结束时加到各玩家初始分数上；不要重复累加余额。
4. 麻将若使用供托等公共积分，单独记录该列。只有规则构成封闭积分体系时，才要求总额守恒。
5. 座位表用于活动安排，保养表用于外部观察记录。个人资料与售后细节私下保存。

- 开局前桌规约定
- OKEY 计分记录
- 麻将积分账页
- 座位与活动记录
- 日常保养记录
